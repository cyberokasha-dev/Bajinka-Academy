# Learner structure

The Flutter learner supports web and Android, eleven chapter headings and 43 topic slots. Chapters 0–3 contain 22 authored topics and 176 activities. Later chapters remain outlines.

Each authored topic provides Learn, Classwork, Homework, Challenge, Project, Assessment, My Notes and My Code. Brief hints and worked solutions are hidden until opened. Notes, code, attempts and progress retain the existing account storage.

Projects progress from small reporting functions into repeated session records, named totals and resilient input handling. Local code checks are independent-study evidence, not university grading.

Only the learner application is present. There is no separate administration application or administration build target.
